# Roadmap

## Completed

- Local onboarding and avatar selection
- Quest CRUD lifecycle and daily completion
- XP, levels, ranks, streaks, achievements, and calendar history
- Habit templates, progress insights, themes, backup export/import, and responsive navigation
- Type checking, linting, pure domain tests, production build, and CI workflow

## Proposed

- Split the current page composition into smaller feature components
- Add richer weekly and monthly charts
- Add versioned backup migrations and stricter record validation
- Expand the starter template and cosmetic collections
- Add browser-level accessibility and responsive interaction tests
- Add an optional local-only reduced-motion preference to every animation
