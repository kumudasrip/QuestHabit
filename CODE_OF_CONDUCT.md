# Code of Conduct

## Our commitment

QuestHabit aims to be welcoming to contributors and users of every background, identity, ability, and experience level. Participation should be respectful, inclusive, and focused on improving the project.

## Expected behavior

- Be kind, constructive, and specific.
- Assume good intent while addressing impact.
- Respect different experience levels, viewpoints, and communication styles.
- Keep issues, reviews, and discussions focused on the work.
- Accept feedback gracefully and help others learn.
- Protect other people's personal information.

## Unacceptable behavior

Harassment, discrimination, personal attacks, threats, deliberate intimidation, unwanted sexual attention, doxxing, publishing private information, and targeted disruption are not acceptable. Trolling, bad-faith review behavior, or repeated attempts to derail project discussions may also result in enforcement action.

## Scope

This code applies to project repositories, issue and pull request discussions, project communication channels, and public interactions where someone is representing QuestHabit.

## Reference

This document is a project-specific code of conduct inspired by the principles commonly used in the Contributor Covenant. It does not claim formal adoption or certification of a specific Contributor Covenant version.
